# Ejercicios Java - Semana 1

**Autor:** Alexis Tuz

## Descripción del Proyecto
Repo de la Semana 1 de la Academia Java con Xideral. El objetivo de esta semana fue afianzar los conceptos fundamentales de Java. Los ejercicios abarcan desde el manejo de tipos primitivos, control de flujo y operaciones con Strings, hasta los pilares de la programación orientada a objetos como encapsulamiento, herencia, interfaces y polimorfismo. Además, se tiene un archivo PDF con respuestas a preguntas teóricas del capítulo 1 del libro Oracle® Certified Professional Java SE 17 Developer Study Guide
